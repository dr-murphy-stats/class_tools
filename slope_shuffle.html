Slope Shuffle Test

If x and y were not related (β = 0), how far from 0 could a sample slope land just by chance? Shuffle the y-values to find out.

2. Shuffle the y-values

What does a shuffle do?
  • Each x-value stays with its person.
  • The y-values are gathered up and dealt back out at random, like shuffling a deck of cards and handing one card to each person.
  • No values are added or removed, so the y-values keep the same mean and spread. Only which x each y is paired with changes.
  • Because the pairing is random, any link between x and y is broken. A shuffled data set shows what the data could look like if β = 0.

Why does shuffling work?

Shuffling the y-values keeps every x-value and every y-value, but pairs them at random. Any link between x and y is broken, so each shuffled data set is what the data might look like if β = 0.

The shuffled slopes pile up around 0. If our sample slope b sits well inside that pile, a slope like ours is easy to get by chance. If it sits far out in the tail, chance alone is a poor explanation.

The proportion of shuffled slopes at least as extreme as b estimates the p-value. The t-test gets nearly the same answer from a formula and the t-table. Because the shuffles are random, your proportion will differ a little from a classmate's.
